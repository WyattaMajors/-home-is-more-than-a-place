# Home Is More Than a Place

A student-led website project about homelessness, with a focus on learning,
awareness, community resources, and measurable local impact.

## Files
- `index.html` — the website
- `style.css` — design and responsive layout
- `script.js` — mobile navigation

## Before publishing
1. Replace placeholder text with your own verified research.
2. Add statistics only when you have a reputable source.
3. Add local information only after confirming it with the relevant organization.
4. Ask permission before publishing anyone's story, quote, photo, or identifying information.
5. Update the Impact numbers only with real, documented results.
